# Projeto Técnico — Sistema de Fertirrigação (Injeção em Pivô Central)

Anteprojeto/memorial descritivo do sistema de fertirrigação com 2 caixas
independentes de 20.000 L, recirculação individual por caixa (retorno
tangencial + jato de varredura, sucção afogada) e 1 bomba de injeção
compartilhada, com troca manual entre caixas via coletor de seleção.
Sem automação nesta fase.

## Conteúdo desta pasta

- `Projeto_Fertirrigacao_Memorial_Descritivo.docx` — memorial descritivo
  completo: objetivo e escopo, conceito geral, descrição dos componentes,
  memorial de cálculo (vazão de injeção, dimensionamento das bombas de
  recirculação e injeção, diâmetros de tubulação), sequência operacional de
  troca manual de caixas, lista de materiais e recomendações de instalação,
  operação e segurança.
- `fluxograma-fertirrigacao.png` — fluxograma (P&ID) do sistema, com a
  numeração dos equipamentos da linha de injeção (1. Registro de seleção →
  2. Filtro → 3. Bomba de injeção → 4. Medidor de vazão → 5. Manômetro →
  6. Válvula de retenção → 7. Ponto de injeção na adutora do pivô).

## Premissas assumidas (a validar em campo)

- Pressão na adutora do pivô no ponto de injeção: 30–35 m.c.a. (a confirmar).
- Critério de renovação de volume para recirculação: 3 renovações/hora.
- Perdas de carga localizadas na linha de injeção: ≈ 5 m.c.a.

Este documento é um anteprojeto técnico; recomenda-se revisão por engenheiro
responsável antes da execução, com emissão de ART/RRT quando aplicável.
